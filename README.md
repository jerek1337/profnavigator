# ПрофНавигатор FinTech

Чат-бот для школьников 6–11 классов. За 3–5 минут выясняет любимый предмет, склонности, интересы, класс и цель. Затем:

- подбирает 2 профессии из финтеха, экономики и анализа данных;
- объясняет выбор с помощью ИИ;
- рекомендует профиль олимпиады «Финатлон»;
- составляет маршрут развития на 3 месяца;
- через 7 дней возвращается с новым советом.

Работает в MAX, Telegram, в веб-версии и как виджет на школьном сайте. Из зависимостей нужен только Python 3.10+.

## Запуск

Сценарий в консоли, без токенов и интернета:

```bash
python main.py --cli
```

С ботом в мессенджере — скопируйте `.env.example` в `.env`, заполните `MAX_TOKEN`:

```bash
python main.py
```

В Docker:

```bash
docker build -t profnavigator .
```

```bash
docker run -d --env-file .env -p 8080:8080 -v $(pwd)/data:/app/data profnavigator
```

Без ключей ИИ бот работает целиком на шаблонных ответах.

## Настройка

| Что | Переменные | Где взять |
|---|---|---|
| Бот в MAX | `MAX_TOKEN`, `BOT_LINK` | платформа для партнёров MAX, dev.max.ru |
| Telegram | `TELEGRAM_TOKEN` | @BotFather |
| YandexGPT | `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | Yandex Cloud, сервисный аккаунт с ролью `ai.languageModels.user` |
| GigaChat | `GIGACHAT_AUTH_KEY` | developers.sber.ru |
| OpenAI-совместимый API | `OPENAI_API_KEY`, `OPENAI_BASE_URL` | любой совместимый сервис |
| Веб и ссылки | `PUBLIC_URL`, `ADMIN_TOKEN` | ваш домен с https |

> Адрес API MAX (`MAX_API_URL`) сверьте с dev.max.ru: в документации встречается и `platform-api2.max.ru`. Токен передаётся только заголовком `Authorization`, режим `MAX_AUTH_MODE=query` платформа больше не поддерживает.

## Что внутри

Сценарий:

1. Приветствие с кнопками «Начать» и «Как это работает».
2. Пять вопросов: `subject`, `skills`, `interest`, `grade`, `goal`. На каждый можно ответить кнопкой или текстом; есть прогресс, кнопка «Назад» и подсказки при непонятном ответе.
3. Подбор профессий: сначала таблица сочетаний `RULES`, для остальных случаев — взвешенный подбор из 8 профессий.
4. Совет от ИИ. Цепочка YandexGPT → GigaChat → OpenAI, при сбое — шаблон.
5. «Финатлон»: профиль и ссылка на fin-olimp.ru, переходы учитываются в аналитике.
6. Маршрут на 3 месяца: основы → практика и олимпиада → школьный проект. Сохраняется, повторно не генерируется.
7. Напоминание через 7 дней. Отключается кнопкой или командой `/stop`.

Команды: `/start`, `/result`, `/finathlon`, `/route`, `/restart`, `/help`, `/stop`, `/forget`. После теста боту можно задать свой вопрос о профессиях — с дневным лимитом, текст вопросов не сохраняется.

Веб (`http://localhost:8080`):

| Адрес | Назначение |
|---|---|
| `/` | веб-версия чата; из мессенджера открывается с тем же профилем |
| `/widget.js` | виджет для школьного сайта: `<script src="https://ВАШ_АДРЕС/widget.js" defer></script>` |
| `/dashboard?token=…` | аналитика: воронка, конверсия, профессии, предметы, классы, цели, источники, динамика за 14 дней, ошибки |
| `/poster?source=corridor` | плакат A4 с QR-кодом; метка `source` показывает, откуда пришли ученики |
| `/health` | состояние сервиса и ИИ-провайдеров |

QR-код требует `pip install qrcode`, в Docker ставится автоматически. Метки источников: `corridor`, `class_hour`, `school_chat` и любые свои.

## Структура

```
main.py                 точка входа, запуск и перезапуск компонентов
config.py               настройки из .env
core/
  content.py            вопросы, профессии, тексты — редактировать здесь
  engine.py             сценарий диалога
  matching.py           подбор профессий и профиля олимпиады
  ai.py, prompts.py     ИИ-провайдеры и промпты
  templates.py          ответы без ИИ
  storage.py            SQLite
  analytics.py          расчёт метрик
  scheduler.py          напоминания
  links.py              подписанные ссылки
adapters/               MAX, Telegram, веб, консоль
web/                    чат, дашборд, плакат, виджет
tests/                  40 тестов
```

## Перед запуском в школе

- Сверьте на fin-olimp.ru описания профилей и сроки «Финатлона».
- Проверьте книги и курсы в `core/content.py`.
- Преимущества при поступлении дают победы и призовые места, а не участие; размер зависит от правил вуза. Бот говорит об этом именно так.
- Бот собирает минимум данных: ответы теста и технические события, без имён в аналитике. Ученик удаляет всё командой `/forget`.
